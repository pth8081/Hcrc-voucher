Cap API key moi cho doi tac

Key duoc gan voi 1 tai khoan nhan vien co san (khong ap dung cho tai khoan quan tri) - khi doi tac goi POST /api/v1/vouchers/check hoac /redeem kem header X-API-Key, he thong xu ly y het tai khoan do tu dang nhap goi API (dung diem tieu/quyen cua tai khoan do). Neu can phan biet nhieu diem tieu qua API, tao 1 tai khoan rieng cho tung diem tieu (man hinh "Tai khoan"), roi cap key cho tung tai khoan do.

Key chi hien thi 1 LAN DUY NHAT nay - sao chep va gui cho doi tac ngay. Sau khi roi trang nay, khong the xem lai (chi tao key moi neu bi mat).
